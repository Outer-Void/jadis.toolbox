# Testing and evidence

```sh
python -m pytest -q                       # unit, fixture and integration tests
ruff check src tests tools && ruff format --check src tests tools && mypy
jadis profiles validate && python tools/repo_hygiene.py
```

## Evidence levels

As of 2026-10-26, first release, commit recorded in the credits ledger.

| Level | Status |
|---|---|
| UNIT_TESTED | Yes: model, redaction, profile validation, classifier invariants (every signal combination) |
| FIXTURE_TESTED | Yes: synthetic Termux (with and without storage), PRoot Debian 13, native Debian 13, CI Debian, an ambiguous Android+Debian host and a blank machine (`tests/fixtures`, generated by `tests/make_fixtures.py`). Variants cover missing Git, broken Python, old Python, duplicate and dead PATH entries, JDK mismatch, incomplete and dangling SDKs, missing, unsupported and failing Vulkan, malformed, timed-out and permission-denied tool output, root without sudo, and no network |
| INTEGRATION_TESTED | Yes, on a real temporary filesystem: dry-run zero mutations, exact and idempotent repairs, managed blocks preserving user text, rollback, interrupted runs, declined authorization, doctor/env/report zero mutations, credential-free backups |
| BUILD_TESTED | Yes: wheel built, installed into a fresh virtualenv, `jadis --help`/`env`/`doctor` run from the installed script |
| PROOT_VALIDATED | **Yes, on one machine:** Debian 13.7 under proot-distro on Android (aarch64), classified `proot-debian` with high confidence; doctor `outer-void`: 27 PASS, 7 WARN, 0 FAIL; real findings: Termux `pkg` on the guest PATH, a dangling `ANDROID_HOME` with its file and line. A real BLUX subprocess call (`blux run environment.doctor --project .`) succeeded with a receipt; a mutating capability was rejected |
| TERMUX_VALIDATED | **No.** jadis has not been run in native Termux, only against fixtures |
| DEBIAN_VALIDATED | **No** for native Debian 13. The CI `debian:13` container job provides that evidence once it has run on GitHub |
| HARDWARE_VALIDATED | **No** (no GPU/Vulkan device run) |
